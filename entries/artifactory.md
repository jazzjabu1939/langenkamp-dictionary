# Artifactory

**JFrog Artifactory is a repository manager for storing, versioning, governing, and distributing software artifacts.**

An artifact is a built object used or produced by software delivery: a package, binary, container image, library, model, or release bundle. Source control stores the recipe. Artifactory stores the ingredients and finished packages that the build and deployment systems actually consume.

The name is proprietary, although people sometimes use it loosely for the category. The generic terms are *artifact repository* or *repository manager*. Artifactory supports many package ecosystems and can serve as a controlled intermediary between an organization and public registries.

That intermediary role makes it part warehouse, part customs post. It can preserve versions, cache dependencies, enforce access rules, attach provenance, scan components, and prevent every build machine from reaching directly into the public software supply chain.
