Claude Desktop is Anthropic's native macOS and Windows application for interacting with the *[Claude](claude.md)* model family. The application launched in October 2024 and later added *[Model Context Protocol](mcp.md)* (MCP) support, allowing it to connect to servers that expose files, databases, tools, and other resources.

Claude Desktop was an early public surface for MCP. It demonstrated the pattern of a desktop AI client using a standard protocol to reach capabilities outside the model itself. The application also gives non-developers access to Anthropic's models without requiring API code.

For this Dictionary, Claude Desktop is chiefly a product example of the protocol layer described under *[Commercial Legibility](commercial-legibility.md)*.
