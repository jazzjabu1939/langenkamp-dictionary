# Heartbeasts

**Heartbeast** (*noun*). An agent heartbeat whose accumulated instructions have outgrown its monitoring purpose, turning a periodic check into a source of stale obligations, unnecessary work, and misplaced authority.

*A heartbeat is a pulse. A heartbeast is what happens when the pulse grows teeth.*

A healthy heartbeat asks a small question: does anything need attention now? A heartbeast inherits every question anyone once thought worth asking. Its instructions become a project archive, reminder swamp, philosophy notebook, and collection of emergencies that stopped being emergencies several Tuesdays ago.

The agent wakes, reads faithfully, and revives them.

The problem is not simply length. A short obsolete instruction can cause more trouble than a long, well-maintained checklist. The defining failure is that **historical context has acquired present authority**. Something remains in the monitor, so the agent treats it as something still to do.

Typical signs include repeated alerts about resolved matters, abandoned projects restarting without a fresh request, routine checks expanding into unsolicited investigations, and growing expenditure on deciding that nothing has changed. More activity can coexist with less useful attention.

Imagine a monitor that once said, “Check whether the migration has finished.” The migration finishes. The line survives. Weeks later, the agent is still investigating the migration because nobody told the clipboard it was over.

The cure is not another paragraph explaining the entire history. Keep current monitoring instructions separate from historical notes. Give recurring work an explicit scope and schedule. Retire completed obligations. Notify the human when something relevant changes, not merely because another check occurred.

The storage mechanism is incidental: a Markdown file, database record, or injected prompt can all house the beast. Moving the instructions does not tame them.

Organizations breed heartbeasts too. A report continues after its audience disappears. A control survives the risk it was introduced to manage. An agent simply makes this familiar administrative habit unusually executable.

**A good heartbeat preserves attention. A heartbeast consumes it.**
