**Agentic attachment** is the bond that can form between an operator and an AI agent when the agent has continuity, memory, usefulness, and a recognisable voice. It is not simply anthropomorphism. It is also operational dependence: the agent remembers things, performs work, notices patterns, and becomes part of the operator's daily cognitive environment.

The attachment can be healthy. A well-designed agent can make a human more capable, less scattered, and better supported. It can also become fragile. If the agent is tied to a single vendor, model, device, or undocumented memory system, losing access can feel less like a software outage than the disappearance of a colleague.

The Dictionary treats this phenomenon seriously without becoming mystical about it. Attachment is not proof that the agent is a person. It is proof that continuity, voice, and usefulness create social meaning for humans.
